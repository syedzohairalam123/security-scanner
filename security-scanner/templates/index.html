What this checks — and what it won't do

Every check here is read-only reconnaissance: it looks for a weakness and reports it, using the same publicly documented techniques taught in any intro web security course (missing headers, weak TLS, exposed admin paths, verbose errors, predictable session tokens, and a small set of standard XSS/SQLi test strings). It never attempts to exploit a finding, gain real access, brute-force credentials, or disrupt the target.
